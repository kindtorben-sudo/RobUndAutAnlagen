SUPABASE – NUR NOCH DIESE ZWEI SCHRITTE

1) ANONYME ANMELDUNG AKTIVIEREN
   Supabase Dashboard
   -> Authentication
   -> Einstellungen / Providers / General Configuration
   -> „Allow anonymous sign-ins“ = EIN

2) SQL AUSFÜHREN
   -> SQL Editor
   -> New query
   -> SUPABASE_SETUP.sql öffnen
   -> kompletten Inhalt einfügen
   -> Run
